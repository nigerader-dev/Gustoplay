# Контент-политика каталога

Каталог — главный актив проекта: от качества метаданных напрямую зависит качество подбора.
Правило простое: **если сомневаетесь, ставьте меньше тегов, но точнее**.

---

## 1. Как устроена запись игры

Ключи компактные, чтобы файл читался глазами (полное описание — в `js/catalog/index.js`):

| Ключ | Что это | Правила |
|---|---|---|
| `t`, `y`, `dev` | название, год, студия | год — год релиза 1.0 (не раннего доступа) |
| `gr` | жанры (`taxonomy.GENRES`) | 1–3 жанра, первый — главный: он влияет на разнообразие выдачи |
| `tg` | теги (`taxonomy.TAGS`) | 6–12 тегов, это «атомы вкуса»; только реальные свойства игры |
| `md` | режимы (`taxonomy.MODES`) | если есть кооп — обязательно `coopOnline`/`coopLocal`; `solo` можно не ставить, если одиночной кампании нет |
| `pl` | `[мин, макс]` игроков | для строго одиночных `[1, 1]`; для MMO `[1, 50]` |
| `pf` | платформы | облако добавляется автоматически для крупных ПК-хитов |
| `pr`, `pv` | ценовая категория и цена в ₽ | `free` для F2P; `subscription` для Game Pass/PS Plus-игр |
| `len` | `[часов до финала, часов на 100 %]` | для бесконечных — второе число большое (`[30, 2000]`) |
| `dif`, `pace` | сложность и темп 1–5 | сложность: 1 = для детей, 5 = соулслайк; темп: 1 = размеренно, 5 = мясорубка |
| `rat` | рейтинг 0–100 | усреднённый по агрегаторам, округляем до целого |
| `mood` | настроения (`MOODS`) | 1–3, самое важное — первым |
| `coopQ` | 0–10, насколько хороша в компании | только для игр с мультиплеером; 8+ = «создана для компании» |
| `gp`, `psp` | есть в Game Pass / PS Plus | отмечаем только фактическое наличие |
| `desc` | `{ru, en}` — одно предложение | без спойлеров, с сутью: что делаешь и почему это интересно |

## 2. Как выбирать теги

- Тег описывает **впечатление и механику**, а не мнение: не «шедевр», а `storyrich`, `difficult`, `cozy`.
- Один тег = один факт. Игра с возможностью коопа на 2 человека — это `coopLocal`/`coopOnline` в `md`
  и `friendlier2` в `tg`, а не `lobbybig`.
- Не ставьте тег, если он справедлив только для части игры (`lowsysreq` для Cyberpunk — нет).
- Настроения (`mood`) — про эмоцию от игры, поэтому они не дублируют жанр: у хоррора может быть
  `scare`, `tense` и даже `laugh`, если игра смешная.
- Спорные случаи решаем в пользу главного опыта: `Escape from Tarkov` — это `hardcoresim`, `tense`, `loot`,
  а не `relaxing`, хотя кто-то и расслабляется на барахолке.

## 3. Что каталог специально не хранит

- **Возрастные рейтинги и наличие русского языка** — пока нет (можно добавить как поля `age`, `ru` при необходимости).
- **Точные цены и скидки** — цены меняются; в карточке ссылки ведут в магазины, где видна актуальная цена.
  Если нужен автоматический парсинг — см. `docs/HOSTING.md`, раздел про Workers и CheapShark.
- **Скриншоты и официальные арты** — из-за авторских прав. Обложки рисуются алгоритмом (`js/cover.js`).
  Можно подключить официальные арты, если у вас есть права/разрешение: положите файлы в `covers/<slug>.jpg`
  и включите `FEATURES.realCovers = true`.

## 4. Санитарные процедуры

```bash
npm run clean    # убрать случайный мусор из данных каталога (после массового редактирования)
npm run check    # проверить дубли, неизвестные теги/настроения, пустые описания, покрытие
npm run test     # убедиться, что интерфейс и все страницы всё ещё рендерятся
```

Валидатор обязательно должен выдавать **0 проблем** перед коммитом. Полезно смотреть,
какие теги не используются вообще (`Неиспользуемые теги` в выводе) — либо добавляйте игры с ними,
либо удаляйте тег из `taxonomy.js`, чтобы не мусорить в фильтрах.

## 5. Как пополнять каталог

1. **Топ-приоритет**: свежие кооп-релизы и хорроры (высокий интерес + много длинных запросов).
2. **Баланс**: следите, чтобы в каждой категории было ≥5 игр. Проверка: `npm run check` показывает покрытие по режимам
   и настроениям — если `coopLocal` есть только у 3 игр, страница `/mode/coopLocal` будет слабой.
3. **Равномерность по бюджету**: у пользователей с фильтром «только бесплатное» должно быть из чего выбирать
   (сейчас F2P-игр около двух десятков — это нормально, но не предел).
4. **Не раздувайте ради количества**: игра без честных тегов всё равно не поднимется в выдаче, а только зашумит подбор.

## 6. Качество описаний

Хорошее `desc` — одно предложение, которое объясняет суть и цепляет:

- ✅ «Четвёрка космических гномов бурит астероиды, отбивается от жуков и держится вместе — идеальный кооп без токсичности.»
- ❌ «Отличная игра с прекрасной графикой и интересным геймплеем.» (нет конкретики)

Английская версия — не дословный перевод, а такой же короткий текст с другой формулировкой.

## 7. Планы по контенту

- Расширенные описания (3–5 абзацев) для топ-50 игр — сильно поднимает SEO страниц `/game/<slug>`.
- Поле «минимум для комфортного ПК» (для фильтра «игры на слабый ноутбук»).
- Локализация UI на другие языки — сейчас ru/en, словари находятся в `js/i18n.js` и добавляются без правок логики.
- Отметка «похожие на …» для ручных «соседних» рекомендаций (сейчас они считаются алгоритмом).
