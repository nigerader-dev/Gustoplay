## Четвёртый проход — отметки, шторка, магазины, тексты (26 сентября 2026)

Пользователь попросил проверить сайт целиком и сдать «под ключ»: баги, орфография,
«скачки текста», дистанции, шторка меню на телефоне, мерцание кнопок отметок,
конкретные ссылки на страницу игры в Steam и удаление магазина Instant Gaming.
Контент-план по всем пунктам — `docs/FIX-PLAN.md` (10 пунктов, статусы и доказательства).

Что исправлено:

1. **Мерцание отметок** (главный баг). Подпись включалась в поток по наведению
   (`display: none → inline`), кнопка росла с 44 до 167px, соседние переносились
   на другую строку, курсор терял кнопку → цикл `mouseover/mouseout`. Теперь подпись
   всегда вне потока (текст остаётся для скринридера), меняется только цвет, подсказка —
   нативный `title`; убран и 1px-сдвиг по наведению.
2. **Шапка** на 901–1920px: шесть пунктов меню не влезали в 1200px, последний уезжал
   на вторую строку (шапка 111px вместо 68px). Рабочая ширина 1280px, подпись логотипа
   не переносится, пункты плотнее, шторка включается с 1140px.
3. **Шторка меню**: 80vw вместо 88vw — на 360px за панелью остаётся 72px страницы,
   а не 43px; крестик, Esc, затемнение и возврат фокуса проверяются автоматически.
4. **Ссылки на магазины**: найден баг — «Открыть в Steam» вела на поиск по названию
   (appid читался из сырой записи, а он приходит из `steam-covers.js`). Исправлено:
   402 игры ведут на `/app/<id>/`. Instant Gaming удалён (данные, UI, i18n, конфиг,
   документация). Для 35 игр без Steam — официальный магазин издателя из
   `js/catalog/store-links.js`; адреса проверяет CI (`links.yml`) и только после
   проверки публикует в аннотациях/комментарии прогона.
5. **Тексты**: `npm run check:text` — словари RU/EN офлайн + правила типографики
   + единый стиль английского (британский). Исправлены «ложня», «превщают»,
   «Рогалевания», «Рогалайк», «фантастка и фэнтезистка», `tower-defense`, `civilization`;
   в интерфейсе «в вишлисте» → «хочу сыграть» и согласование в FAQ.
6. **Скачки текста**: замеры CLS в браузере — 0.000 при загрузке, открытии меню
   и наведении; карточки не двигаются после подгрузки обложек.
7. **Дистанции и обрезка**: длинные слова в карточках переносятся (было обрезание
   на 360px), панели формы «На компанию» по содержимому, короткий плейсхолдер поиска.

Автоматика, которая это держит: `test:visual` (в том числе интерактивный блок
в браузере **с включённой мышью и hover** — в headless Chrome по умолчанию `hover: none`,
из-за чего баг с мерцанием не воспроизводился), `test:css` (`.mark:hover` без правил
раскладки; шапка в одну строку; шторка до 1140px), `check:text`, `check:stores` (CI),
smoke-тест на вид ссылки в Steam.

### Что добавлено в этом проходе (сверх плана)

1. **`check:covers` ловит заглушки** — критерий приёмки «ноль заглушек» теперь проверяется
   скриптом, а не глазами: cover обязан быть `https://`-ссылкой на арт магазина, а не
   `data:`-URI, не SVG-генератором и не файлом из `/covers`. Работает и без сети.
2. **Тест на эмодзи** (`test:functional` §15) — план утверждал, что «тесты это проверяют»,
   но проверки не существовало. Сканируются строки i18n, тексты всех 437 игр и 8 страниц.
3. **`npm run deploy:purge`** — очистка кэша зоны отдельной командой, когда сайт уже
   опубликован, а хост держит старый релиз.
4. **Проверка всех хостов в деплое** — раньше сверялся только apex, хотя релиз разъезжался
   именно между хостами: теперь apex обязателен, а `www` и `pages.dev` при расхождении версий
   дают предупреждение, повторный purge и строку в сводке запуска.

## Что осталось

1. ~~Прогнать `check:covers` там, где есть сеть~~ — **выполнено в CI** на пуше ветки: шаг
   «Обложки» пройден. В песочнице CDN закрыт, локальный прогон теперь честно об этом сообщает.
2. **Смёржить PR #5** — после ревью; ветка проверена, деплой и Pages идут только из `main`.

   меняет высоту вьюпорта), горизонтальный скролл в каталоге с длинными названиями.
4. **Lighthouse** (LCP/CLS/SEO) — замеры зависят от машины, в песочнице не снимались.
5. **Мигание темы** при первой загрузке (~50мс светлой темы) — не фиксится без ослабления CSP
   (инлайн-скрипт запрещён). Осознанно оставлено.
