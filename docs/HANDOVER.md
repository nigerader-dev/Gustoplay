## Что осталось

1. **Прогнать `check:covers` там, где есть сеть** — здесь домены CDN недоступны, локальный
   прогон честно сообщает об этом. В CI он запускается сам при пуше; убедиться, что ветка
   зелёная: `gh run list --branch <ветка>` или вкладка Actions у pull request.
2. **Живые устройства** (iOS Safari, Android Chrome, Firefox) — вёрстка стандартная, но
   шторка/скролл/100dvh стоит пощупать руками. Кандидаты: меню на iOS (адресная строка
   меняет высоту вьюпорта), горизонтальный скролл в каталоге с длинными названиями.
3. **Lighthouse** (LCP/CLS/SEO) — замеры зависят от машины, в песочнице не снимались.
4. **Мигание темы** при первой загрузке (~50мс светлой темы) — не фиксится без ослабления CSP
   (инлайн-скрипт запрещён). Осознанно оставлено.
