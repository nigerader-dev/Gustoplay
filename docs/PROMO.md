# Продвижение: план и готовые черновики

Черновики для внешних площадок. Публикует владелец (или Claude — только с отдельного «да»
на каждую публикацию). Правило всех площадок: сначала польза, ссылка — вторым планом;
одна площадка — один пост; никаких накруток и покупных ссылок (см. docs/SEO.md, § 6).

## Черновик 1 — DTF (блог)

**Заголовок:** Сделал бесплатный подборщик игр: отвечаешь на пару вопросов — получаешь список с объяснением «почему»

Знакомая ситуация: в библиотеке полно игр, вечер свободный, а во что поиграть — непонятно.
Я сделал GustoPlay: короткий квиз (настроение, с кем играете, платформа, сколько времени и денег)
выдаёт список игр, и у каждой написано, почему она подходит именно вам. Отмечаете, во что уже
играли и что понравилось, — выдача пересчитывается.

Что внутри:
- каталог из 593 игр с требованиями к ПК из Steam и проверкой «потянет ли мой компьютер»;
- режим «компания»: подбор под 2–5+ человек с учётом платформ у всех;
- готовые подборки: кооп на ПК, игры на двоих на одном экране, бесплатный кооп, игры для слабых ПК.

Без регистрации, без рекламы-простыни. Буду рад фидбеку: каких игр не хватает и где подбор
ошибся — gustoplay.ru

## Мониторинг

`npm run gsc` — сводка Search Console: запросы, страны, «почти в топе» (позиции 8–20 — какие
страницы дорабатывать первыми), индексация ключевых страниц. `npm run gsc -- --resubmit`
дополнительно переотправляет sitemap.xml.
