## Что сделано по адаптиву (QA-PLAN §3)

- **Бургер-меню** (≤900px): выдвижная панель + оверлей + Esc + возврат фокуса + `aria-expanded/controls`.
- **Шторка фильтров** (≤900px): нижняя панель с бейджем числа активных, кнопкой «Показать N»,
  переживает выбор фильтров и перерендеры.
- **Мобильный hero**: вместо `display:none` — компактная полоса арта (150px → 120px).
- **Брейкпоинты**: 1080 / 900 / 640 / **480** (новый, компактные телефоны).
- **Тач-цели ≥44px**: кнопки, отметки, чипы, табы, опции, свитчи, инпуты, иконки шапки.
- **Компактные карточки** на телефоне: максимум 2 чипа, описание в 3 строки, подписи отметок только у активной.
- **Sticky-навигация квиза** на телефоне + `safe-area-inset`.
- **Защита от переполнения**: `min(Xpx,100%)` во всех сетках, `overflow-x: clip`, `overflow-wrap`,
  ellipsis для длинных названий/меток.
- **Фолбэки**: plain-дубли всех `color-mix`, `@supports` для `backdrop-filter`.

## Скриншоты

Пиксельный прогон выполнен: **85 проверок (5 ширин × 17 маршрутов), провалов 0**,
кадры лежат в `docs/qa-shots/` (в git не коммитятся, см. `.gitignore`).

```bash
npm i -D puppeteer && npx puppeteer install chrome     # обычная машина
npm run test:visual -- --widths=360,768,1024,1440,1920 --shots=all
```

Там, где Chrome скачать нельзя (закрыт `storage.googleapis.com` — песочницы, корпоративные
прокси), браузер берётся из npm-пакета и запускается одной командой:

```bash
node tools/chromium-offline.mjs --run -- --widths=360,768,1440 --shots=all
```

`tools/chromium-offline.mjs` ставит `@sparticuz/chromium` (бинарь внутри npm-тарбола),
распаковывает к нему бандл системных библиотек и передаёт `LD_LIBRARY_PATH` +
`PUPPETEER_EXECUTABLE_PATH` в прогон. Из инструментального: `tools/shots.mjs` сам поднимает
сервер на свободном порту, ждёт отрисовку (`#app .header`) и делит ошибки на «свои» и
внешние (недоступный CDN обложек — не дефект сайта, печатается отдельной строкой; `--strict`
включает и их).

## Что не сделано / риски

1. **Пиксельный прогон** (`test:visual`) — выполнен (см. «Второй проход» и «Шестой проход»).
2. **Живые устройства** (iOS Safari, Android Chrome, Firefox): в песочнице недоступны, вёрстка
   стандартная, но тач-скролл шторок и 100vh-особенности iOS стоит пощупать руками
   (vh в шторках не используется — риск низкий).
3. **Lighthouse-замеры** — в песочнице не снимались (LCP/CLS зависят от машины и сети);
   сдвиги макета измерены отдельно: CLS 0.000 на 360 и 1440.
4. **Мигание темы** при первой загрузке (тёмная применяется JS после парсинга): inline-фикс
   невозможен — CSP запрещает инлайн-скрипты. Проявляется как ~50мс светлой темы. Не фиксится
   без смягчения CSP — осознанно не трогаем безопасность ради косметики.
5. **Печать** страниц — пропущена (в плане помечена опциональной 🟢).
