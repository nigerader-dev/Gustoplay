## Что сделано по адаптиву (QA-PLAN §3)

- **Бургер-меню** (≤900px): выдвижная панель + оверлей + Esc + возврат фокуса + `aria-expanded/controls`.
- **Шторка фильтров** (≤900px): нижняя панель с бейджем числа активных, кнопкой «Показать N»,
  переживает выбор фильтров и перерендеры.
- **Мобильный hero**: вместо `display:none` — компактная полоса арта (150px → 120px).
- **Брейкпоинты**: 1080 / 900 / 640 / **480** (новый, компактные телефоны).
- **Тач-цели ≥44px**: кнопки, отметки, чипы, табы, опции, свитчи, инпуты, иконки шапки.
- **Компактные карточки** на телефоне: максимум 2 чипа, описание в 3 строки, подписи отметок только у активной.
- **Sticky-навигация квиза** на телефоне + `safe-area-inset`.
- **Защита от переполнения**: `min(Xpx,100%)` во всех сетках, `overflow-x: clip`, `overflow-wrap`,
  ellipsis для длинных названий/меток.
- **Фолбэки**: plain-дубли всех `color-mix`, `@supports` для `backdrop-filter`.

## Скриншоты

В песочнице нет браузера и закрыта сеть для скачивания Chrome, поэтому пиксельные скриншоты
не снимались. Для съёмки на своей машине:

```bash
npm i -D puppeteer && npx puppeteer install chrome
npm run test:visual -- --widths=360,768,1024,1440,1920 --shots=all
# кадры → docs/qa-shots/ (в git не коммитятся, см. .gitignore)
```

Скрипт сам поднимает сервер, проверяет переполнение/консоль/h1/alt/битые картинки и падает
при любой проблеме — годится и для CI с браузером.

## Что не сделано / риски

1. **Пиксельный прогон** (`test:visual`) — запустить локально по инструкции выше.
2. **Живые устройства** (iOS Safari, Android Chrome, Firefox): статическая вёрстка стандартная,
   но тач-скролл шторок и 100vh-особенности iOS стоит пощупать руками (vh в шторках не используется —
   риск низкий).
3. **Lighthouse-замеры** — отложить до `test:visual`-прогона (LCP/CLS зависят от машины).
4. **Мигание темы** при первой загрузке (тёмная применяется JS после парсинга): inline-фикс
   невозможен — CSP запрещает инлайн-скрипты. Проявляется как ~50мс светлой темы. Не фиксится
   без смягчения CSP — осознанно не трогаем безопасность ради косметики.
5. **Печать** страниц — пропущена (в плане помечена опциональной 🟢).
