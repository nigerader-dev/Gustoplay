# Что сделать владельцу вручную

Всё, что можно было сделать из кода, уже сделано и выкладывается автоматически при каждом
слиянии в `main`. Ниже — только шаги, которые требуют вашего личного входа в чужие сервисы
(паспортные данные, банковские реквизиты, подтверждение прав на домен).

После каждого шага, где выдаётся код или ID, достаточно прислать его мне (или вписать
в указанную строку `js/config.js` и сделать коммит) — дальше всё подхватится само.

---

## 1. Реклама: Рекламная сеть Яндекса (РСЯ)

**Почему РСЯ.** Google AdSense с декабря 2024 года не работает с владельцами сайтов из
Беларуси (новые аккаунты не открываются, старые отключены). РСЯ официально работает
с физлицами — резидентами Беларуси: договор-оферта с Yandex Europe AG, выплаты в долларах
на банковский счёт или через Payoneer. Аудитория сайта русскоязычная — для неё РСЯ даёт
лучшую цену за показ из доступных вам сетей.

Источники: [физлица из Беларуси](https://yandex.com/support/partner/ru/payments/with-belarus-individuals.html),
[ИП и юрлица из Беларуси](https://yandex.com/support/partner/ru/payments/with-belarus-legal-entities.html),
[подключение](https://yandex.ru/support/partner/ru/joining/),
[AdSense и Беларусь](https://support.google.com/publisherpolicies/answer/15766875?hl=en).

**Шаги (≈20 минут + модерация, обычно меньше суток):**

1. Войдите в свой Яндекс ID и откройте анкету партнёра: <https://partner.yandex.ru/form>.
   Статус — «Физическое лицо», страна — Беларусь.
2. Добавьте сайт `gustoplay.ru`. Модерация запустится сама.
3. После одобрения создайте 4 рекламных блока типа **«Адаптивный»** (РСЯ → Сайты → Блоки):

   | Название блока | Где стоит на сайте | Куда вписать ID |
   |---|---|---|
   | GustoPlay — главная | под первым экраном главной | `ADS.rsya.blocks['home-top']` |
   | GustoPlay — подбор | в ленте результатов подбора | `ADS.rsya.blocks['results-inline']` |
   | GustoPlay — каталог | в ленте каталога | `ADS.rsya.blocks['catalog-inline']` |
   | GustoPlay — игра | на странице игры | `ADS.rsya.blocks['game-side']` |

   Код вставки копировать не нужно — сайт уже умеет вызывать блоки. Нужны только ID вида
   `R-A-1234567-1`.
4. Пришлите мне 4 ID (или впишите их в `js/config.js` и поставьте `ADS.mode: 'rsya'`).
5. В разделе «Настройки → Реквизиты» укажите адрес, имя латиницей, валюту (USD), SWIFT банка
   и номер счёта/IBAN **или** аккаунт Payoneer; загрузите скан паспорта (подтверждение
   резидентства).

**Налоги.** Доход от РСЯ для физлица из Беларуси — доход из-за рубежа: декларацию и налог
вы подаёте сами (РСЯ налог не удерживает). Точную ставку и сроки уточните в своей
налоговой инспекции — правила меняются.

**Что уже сделано на сайте:** блоки резервируют место (страница не «прыгает» при загрузке
рекламы), реклама загружается только после согласия на cookie, работает при переходах между
страницами без перезагрузки, домены Яндекса разрешены в политике безопасности (CSP),
в тексте «Про рекламу» объяснено, что место в подборке купить нельзя.

> Другие сети (Adsterra, Monetag и т. п.) не рекомендую: в основном это всплывающие окна
> и редиректы — они ухудшают сайт для посетителей и могут понизить его в поиске.

## 2. Чтобы сайт находили в поиске

Технически сайт готов: 780 страниц отрендерены заранее, есть sitemap, robots.txt,
уникальные заголовки, разметка Schema.org, картинки для превью ссылок, а после каждого
деплоя список страниц автоматически отправляется в Яндекс и Bing (IndexNow).
Осталось подтвердить, что сайт ваш.

### Яндекс Вебмастер (главное для русскоязычной аудитории)

1. <https://webmaster.yandex.ru> → «Добавить сайт» → `https://gustoplay.ru`.
2. Способ подтверждения — **«Мета-тег»**. Скопируйте значение `content="…"`.
3. Пришлите мне это значение или впишите в `js/config.js`:
   `SITE.verification.yandex: 'значение'` → коммит. После деплоя нажмите «Проверить».
4. Раздел «Индексирование → Файлы Sitemap» → добавьте `https://gustoplay.ru/sitemap.xml`.
5. «Информация о сайте → Регион сайта» — можно не указывать (сайт не привязан к городу).

### Google Search Console

1. <https://search.google.com/search-console> → «Добавить ресурс» → **«Префикс URL»** →
   `https://gustoplay.ru/`.
2. Способ подтверждения — **«Тег HTML»**, значение `content="…"` → в
   `SITE.verification.google` (или пришлите мне).
3. «Файлы Sitemap» → `sitemap.xml`.

### Bing (по желанию, 2 минуты)

<https://www.bing.com/webmasters> → «Импортировать из Google Search Console».

## 3. Cloudflare (две галочки в панели)

1. **Редирект www → без www.** Сейчас `www.gustoplay.ru` отдаёт тот же сайт — поисковики
   видят две копии (canonical смягчает, но редирект надёжнее).
   Cloudflare → gustoplay.ru → Rules → **Redirect Rules** → Create rule → шаблон
   «Redirect from WWW to root» → Deploy.
2. **Право Cache Purge для токена деплоя.** В логах деплоя есть предупреждение: без него
   при выкладке не очищается кэш, и новая версия на `gustoplay.ru` может появиться с задержкой.
   Cloudflare → My Profile → API Tokens → токен, который лежит в секрете
   `CLOUDFLARE_API_TOKEN` → Edit → добавить **Zone → Cache Purge → Purge** для gustoplay.ru.

## 4. Необязательно, но полезно

- **Яндекс Метрика** — статистика посещений и поисковых запросов. <https://metrika.yandex.ru>
  → «Добавить счётчик» → номер счётчика в `ANALYTICS.yandexMetrika`. Подключение уже
  настроено: счётчик грузится только после согласия на cookie.
- **Google-вход и письма сброса пароля** — инструкция в `docs/ACCOUNTS.md`
  (нужны Client ID Google и ключ Resend).
