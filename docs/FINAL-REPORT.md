## Детали по незакрытому (явно)

**Заход 4 — 491 игра из цели 1000+.** Причина: партия собирается конвейером
(`tools/pull-catalog-candidates.mjs` в Actions, прогоны 36339299053 и др.), каждая
игра требует обложку, описания ru/en, HLTB-время и проверку источников; выдумывать
игры нельзя по правилам сессии. Что есть: 118 игр с коопом за одним экраном (цель
«не меньше 400 с коопом» не достигнута — это 118, не 400; источник цифры —
`npm run check`: «Кооп за одним экраном — 118»). Дальше: батчами по ~50 игр в неделю
по мере готовности данных сборщика.

**Заход 8 — юртексты.** Гейт: применять формулировки без согласования нельзя.
Подготовлено: `docs/LEGAL-REVIEW.md` — 9 конкретных правок (оператор, дата редакции,
D1-обращения поддержки, чекбокс согласия, Google Limited Use, возраст, перечень cookie,
применимое право, статус рекламы), инвентаризация ПД по коду, список «что могу
только я» из 10 пунктов. После одобрения применение — один коммит.

**Гейты без изменений** (требуют решений заказчика): реклама/ключи сетей, отправка
писем (Resend), Google OAuth Client ID, домен/DNS/деплой в прод, всё про деньги,
одобрение юртекстов, массовые правки каталога.
